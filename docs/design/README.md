# Welcome-screen concepts

The two concept images in this directory were generated as layout references for the Step 1 welcome screen. They intentionally do not reproduce the Loop logo. Their reserved/blank artwork area is replaced in the implementation by the byte-identical approved master from `reference-assets/brand/loop-logo-approved-master.jpeg`.

The production UI follows the supplied brand tokens and uses flat evergreen controls. Any soft gradient or placeholder outline appearing in a concept is not an approved brand treatment and is intentionally excluded.
